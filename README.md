# 淘宝用户行为数据分析

一个面向数据分析实习求职的完整项目，围绕“数据采集 -> 数据清洗 -> 数据存储 -> 可视化分析 -> 业务洞察”构建了完整闭环。

---

## 项目简介

传统数据分析项目往往只停留在“跑通代码”或“画出图表”，而这个项目进一步把分析结果与业务决策挂钩：

- 从 Kaggle
 获取淘宝用户行为公开数据集（约 1 亿条原始记录）
- 使用 Python（Pandas）进行数据清洗与预处理，解决时间戳格式错误、数据抽样等真实问题
- 设计 MySQL 数据库表结构，将清洗后的数据落地存储
- 基于 Power BI 构建交互式看板，直观呈现用户行为分布与转化漏斗
- 输出结构化业务洞察，帮助理解用户从浏览到购买的流失节点

---

## 数据说明

- **数据来源**：淘宝用户行为公开数据集,数据来自Kaggle
- **原始规模**：约 1 亿条
- **抽样规模**：60 万行

### 字段说明

| 字段名 | 含义 | 示例 |
| :--- | :--- | :--- |
| user_id | 用户唯一标识 | 1 |
| item_id | 商品唯一标识 | 2268318 |
| category_id | 商品类目 ID | 2520377 |
| behavior_type | 行为类型（pv/fav/cart/buy） | pv |
| timestamp | 行为发生时间（10位秒级时间戳） | 1511544070 |

---

## 分析结论

| 行为类型 | 数量 | 占比 |
| :--- | :--- | :--- |
| 浏览（pv） | ~538,830 | 89.8% |
| 加购（cart） | ~32,950 | 5.5% |
| 收藏（fav） | ~12,210 | 2.0% |
| 购买（buy） | ~16,000 | 2.7% |

### 转化漏斗

| 转化路径 | 转化率 |
| :--- | :--- |
| 浏览 → 购买 | 2.4% |
| 加购 → 购买 | 39.7% |

### 核心洞察

1. **加购环节流失最严重**：60.3% 的用户加购后未完成购买
2. **整体购买转化率偏低**：2.4% 的浏览→购买转化率处于行业中等偏低水平
3. **收藏行为占比小**：仅 2.0%，用户更倾向于直接加购
